# 2026-08-27 工作日志

## 序章/第一章场景黑屏（真因定位 + 修复）
- **现象**：进入序章 office / 第一章 lobby 等 screens 场景整屏纯黑，无报错。此前（08-26）因 `_makeItemBtn` 崩溃从未真正渲染过场景，修好崩溃后才暴露黑屏。
- **误判与纠正**：先误判为"SceneManager root 未挂载渲染树"，加 `UI.GetRoot():AddChild(root)` 无效。真正根因：**引擎 `Widget:new(props)` 仅接受单参数 `props`（`urhox-libs/UI/Core/Widget.lua:308`），且不处理 `props.parent`**。SceneManager 大量 `UI.Panel(parent, {props})` / `UI.Label` / `UI.Button` 双参数调用，第二参数 `props` 被完全忽略 → 所有控件以**空 props** 创建（无尺寸/背景/样式）→ 不渲染 → 黑屏。Menu/Opening 用单参数 `UI.X({...})` 故正常能显示。
- **修复**：SceneManager 顶部加兼容 wrapper `Panel/Label/Button`，把 `UI.X(parent, props)` 转为 `ctor(props)` + `parent:AddChild`（兼容 `X(props)`/`X(parent,props)`/`X(nil,props)` 三种形式），并 `replace_all` 切换调用。EnterScene 的 root 仍显式 `UI.GetRoot():AddChild(root)`。commit 7318552，构建 100%，lint 0。
- **结论**：08-26 日记第 6 次的"root 未挂载"判断是错误的，真正坑是"双参数 UI 构造被引擎吞掉第二参"。已修正 MEMORY.md。排查 UI 黑屏第一优先级：确认构造调用是否误用双参数 `(parent, props)`。
