## 修复运行时错误 ✅（2026-08-24）
- 错误：`main.lua:260 attempt to call a nil value (method 'GetFrameTime')` + `Failed to parse script file[main.lua]`。
- 根因1：UrhoX 是事件驱动，**无** `engine:IsExiting()/GetFrameTime()/FrameNext()`，`main.lua` 手写 while 主循环调用了这些 nil 方法。
- 根因2：全项目缺 `UI.Init()` + `UI.SetRoot()`，各 UI 系统的 root Panel 只用 `:Show()`（仅 SetVisible(true)）从未挂载渲染树，即使不报错也不会渲染。
- 修复：
  1. `main.lua`：`UI.Init({ scale = UI.Scale.DEFAULT })` + `UI.SetRoot(全屏 box-none 总 root)`；删 `Run()`；`Update(dt)` → `HandleUpdate(eventType, eventData)` 用 `eventData["TimeStep"]:GetFloat()`；`SubscribeToEvent("Update","HandleUpdate")`。
  2. 5 个 UI 系统（MenuSystem/SceneManager/NoteSystem/DialogueSystem/OpeningSystem）：`M.ui.root:Show()` → `local uiRoot=UI.GetRoot(); if uiRoot then uiRoot:AddChild(M.ui.root) end`（Destroy 会自动从 parent 移除，无需额外清理）。
  3. `SceneManager`：删 `DrawBackground()` 的 raw NanoVG（nvgBeginFrame 等错误签名），背景改用 `M.sceneColors` 的 backgroundColor。
- 验证：lint 0 错误；构建成功（commit a171afe）；watcher `state.json` lastError:null，无 ERROR/attempt to call/nil 日志。
