## 修复：SceneManager SetStyle 调用崩溃（2026-08-26 晚）
- **报错**：`urhox-libs/UI/Core/Style:363: bad argument #1 to 'for iterator' (table expected, got string)`，发生在 `SceneManager:91`（EnterScene 创建悬停标签后 `SetStyle("visible", false)`）。
- **根因**：引擎 `Widget:SetStyle(props)` 只接受**单个 table 参数**，我误写成 `SetStyle("visible", false)`（key/value 两参数），导致字符串 `"visible"` 被当 props 传入 `NormalizeColorProps`，`pairs("visible")` 崩溃。共遗漏 9+ 处（hoverNameLabel 显示/隐藏、screenPanel backgroundColor/backgroundImage、minimap borderColor/borderWidth、dot backgroundColor、navButton opacity、视差层/主角每帧 `SetStyle("left", ...)` 等）。
- **修复**：全部改为 `SetStyle({ key = value })`；`SetStyle("opacity", 1/0.2)`、`SetStyle("visible", ...)`、`SetStyle("left", ...)`、`SetStyle("backgroundColor"/"backgroundImage"/"borderColor"/"borderWidth", ...)` 一律包成 table。搜索 `scripts/` 确认无残留 `SetStyle("` 形式。
- **验证**：commit 050e2c6，构建成功；新运行日志无该 ERROR（仅 `UI.Init() called twice` 警告，非致命），`EnterScene` 能顺利执行到创建 UI 之后。
- **经验**：`SetStyle` 永远传 table，这是 UrhoX UI 库的硬性约定（与常见 `SetStyle(key, val)` API 不同），所有 widget 的样式动态修改都要遵守。
