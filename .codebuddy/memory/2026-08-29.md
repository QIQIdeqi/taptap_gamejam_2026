### Maker 构建遇 `behind 1` 的处理流程（重要，会反复遇到）
Maker 云端会在构建后**自动为新资源生成 `.meta` 文件并推送一个 sync 提交**，导致本地落后 1 个提交，下次构建被 `remote_rejected / needs_pull` 阻止。
**解决顺序**：
1. `git stash push -- <改动文件>` 清空工作区（裸 `git pull` 会因 DNS 失败，不用）
2. 再次调用 `maker_build_current_directory` → 此时 Maker 提示 `needs_pull` 并**授权**执行 `git pull --ff-only`
3. `git pull --ff-only origin main`（此时能成功，拉回云端生成的 `.meta` 提交）
4. 再次 `maker_build_current_directory` → 构建成功
5. `git stash pop` 恢复文件
- 注意：本地有未提交改动时 Maker **不会**授权 pull，必须先 stash。

1. `git stash push -m "..."`（**改动含代码时也必须 stash**，Maker 只在 `status: clean` 时才授权 pull）
2. 调 `maker_build_current_directory` → 返回 `needs_pull` 并明确授权
3. `git pull --ff-only origin main`（此时 DNS 可用，能拉回 `.meta`）
4. `git stash pop`
5. 再调 `maker_build_current_directory` → 成功
- 补充：构建可能返回 `Request timed out`，但**改动往往已提交推送**，务必用 `git log --oneline -2` + `git status --short` 复核，勿重复构建。

### 序章分镜系统（commit `71501fb`）
用户要求：按 CSV 台词做分镜稿 → 生成图片 → 代码实现镜头切换与角色显示。
- **分镜稿（CSV line1-13 = opening_prologue_1/2/3）**：镜1 事务所地铺（李志被叫醒）→ 镜2 **镜头切换**厨台煮泡面（陈雯音旁看）→ 镜3 切入回忆·房间门（黑屏打 2036年8月8日 14:20）。
- **新增 3 张分镜场景图**（image_gen，1536×1024 横向可用）：`bg_office_futon.png` / `bg_office_kitchen.png` / `bg_flashback_door.png`。CSV 的 `background` 列已按分镜批量改写（prologue_1=5行→futon，_2=5行→kitchen，_3=13行→door）。
- **`GameData.OpeningShots`**：分镜表，key=对话id，含 `actors`（角色站位）/`caption`/`transitionDur`。角色立绘实际比例 **805×1200 = 0.671**（`char_lizhi/wenyin/sister` 一致）。actor 字段：`x/y`=底部中心归一化坐标、`h`=占屏高比例、`ratio`=立绘宽高比。
- **`OpeningSystem` 改为双缓冲镜头**：
  - `CreateShotPanel()` 建一个"镜头"= 背景 + 暗化遮罩 + `_actorLayer` 角色层
  - `FillShot(panel, dialogueId)` 填背景并按 OpeningShots 画角色（底边对齐 `y`、以 `x` 为中心）
  - `TransitionToShot(id)` 后景填内容 → 前后景**交叉淡入淡出**(`opacity` 0→1/1→0) → 完成后交换前后景
  - `M.Update` 驱动过渡；回忆镜 `transitionDur=1.1` 放慢
- **关键坑（已规避）**：切换时若新建 Panel 再 `AddChild`，会盖在对话 UI 之上（后添加的在上）。故采用**两个常驻 Panel 双缓冲**、只在建场时 AddChild 一次，之后只换内容与 opacity，保证镜头永远在对话下层。
- `opacity` 取值 0~1（与 `fontColor` 的 0~255 alpha 不同）。
- **watcher 仍未恢复**：构建超时导致日志 watcher 起不来，手动 `Start-Process` 拉起也失败（缺 MCP 会话上下文，进程立即退出）。读日志前需先确认 `watcher.pid` 对应进程存在。
