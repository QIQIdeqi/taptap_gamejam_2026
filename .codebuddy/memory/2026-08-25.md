## SceneManager 运行时报错修复（2026-08-25）
- 错误：Maker 报告 3 条 ERROR，根因是 `scripts/SceneManager.lua:16` 的 `require("Input")` 触发 Module not found，连带 `main.lua` 解析失败（Lua Execute failed）。
- 根因：引擎**无 Input 模块**。输入接口由引擎以**全局变量 `input`** 注入（main.lua/NoteSystem.lua 已在使用）；可用方法仅 `input:GetKeyPress(KEY_*)` 与 `input:GetMouseButtonPress(MOUSEB_*)`。我之前误记 MEMORY 第36行"有 GetKeyDown"，据此误写了 SceneManager（require Input + GetKeyDown + GetMousePosition），全部不存在。
- 修复：删除 `require("Input")`；`GetKeyDown`→`GetKeyPress`；移除不存在的 `GetMousePosition` 鼠标边缘逻辑（改为纯方向键滚动）。
- 同步阻塞：每次构建前若"远端领先 1 个 sync 提交 + 本地未提交改动"，需 `git add + 英文 commit message（PowerShell 中文乱码）+ git pull --rebase origin main` 后再 `maker_build`。已走该流程，构建成功（commit 28d3989，pushed）。runtime.log 仍停在修复前旧错误，待用户在 Maker 预览重新加载验证。
