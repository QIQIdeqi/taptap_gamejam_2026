## 四、风格一致性检查清单

生成后请逐项核对：
- [ ] 线稿是否干净利落（非写实素描风）
- [ ] 上色是否为赛璐璐/平涂（非厚涂油画风）
- [ ] 人物比例是否修长（8头身左右，非Q版/三头身）
- [ ] 配色是否低饱和暖调（非高饱和赛博朋克霓虹）
- [ ] 场景是否有叙事氛围感（非纯装饰画）
- [ ] 人物立绘背景是否纯净（透明/纯白，无杂乱背景元素）
