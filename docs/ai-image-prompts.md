# 《异视·黄昏事务所》AI图像生成 Prompt 套装（侧视横版 · 视差多层版）

> **统一风格基准**：日系二次元动漫（Japanese Anime Style）
> - 干净利落的黑色线稿 + 柔和赛璐璐上色（cel-shading）
> - 人物修长比例（8 头身），面部简约但表情传神
> - 暖调低饱和配色，光影柔和不刺眼
> - 场景注重氛围感与叙事性
> - 适用工具：TapTap Maker `batch_generate_images` / Midjourney v6 / NijiJourney / SD (Anime)

## 〇、渲染规格总览（务必先读，决定出图成败）

### 视角
**侧视横版（side-view）**：摄像机从侧面平视，角色双脚站在「地面线」上，场景向左右横向展开。
不是俯视等距，不是纯正面 UI 面板。参考：视觉小说 / 冒险游戏的 2D 横版场景展示模式。

### 视差三层（核心）
每个场景拆成 **3 张图层** 分别出图，运行时以不同速度横向滚动，形成纵深：

| 层 | 视差系数 | 建议宽度 | 内容 | 边缘处理 |
|----|---------|---------|------|---------|
| **背景 BG** | 0.35（慢） | ≈ 0.6×场景总宽 | 天空 / 远景建筑 / 海平线 / 远山 / 窗外景色 | 左右自然淡出到纯色 |
| **中景 MID** | 1.0（基准） | = 场景总宽 | 场景主体 + **地面线** + 可交互物件基座 | 标准 |
| **前景 FG** | 1.4（快） | = 场景总宽 | 近景遮挡：栏杆 / 盆栽 / 吊灯 / 桌椅前缘 | 左右半透明渐隐避免硬边 |

> 视差效果：角色向右走时，中景正常移动，背景慢慢挪、前景飞快掠过。

### 统一尺寸
- **所有图层高度统一 1080px**（@1080）。
- **地面线（ground line）固定在中景层 y = 780px**（1080 高基准）。角色立绘脚底对齐此线。
- 三层必须**共享同一地平线高度、同一光源方向、同一透视消失点**，拼接后才连贯。
- 中景层**不要画角色**（角色是独立透明立绘叠加在中景之上）。
- 场景三层均为**不透明**（含天空/地面/墙体），无需透明。

### 横向拼接规范（可拼接）
- 场景总宽建议 **2240px（=2×1120）** 或 **3360px（=3×1120）**。
- 由 2~3 段无缝拼接成单张（拼接在出图后由你手动/工具拼，或让模型一次出超宽图）。
- 段落接缝处**避免放置独立物件中心**；物件可跨段，但主体避开接缝 ±120px。
- 每段共享同一水平地平线、同一光源、同一消失点。
- 出图后横向拼接为单张，命名见各场景（如 `bg_hotel_lobby_mid.png`）。

### 角色立绘约定（叠加层）
- 透明背景 PNG，正面站立全身，约 **2:3（768×1152）**。
- **脚底对齐地面线（y=780 对应立绘底部）**，正面朝前（引擎中左右移动时不翻转立绘）。
- 姿势自然放松（单手插兜 / 垂手），便于融入场景。
- 不要画场景、不要画地板倒影（倒影由引擎或单独前景处理）。
